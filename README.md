# Xbox 360 Recomp Ports

Native Android ports of Xbox 360 games, built for the **Retroid Pocket 6** with the
[ReXGlue](https://github.com/rexglue/rexglue-sdk) static recompiler.

| Folder | Game | Status |
|---|---|---|
| [UniverseAtWar/](UniverseAtWar/) | Universe at War: Earth Assault | Full-speed, smooth play on the Retroid Pocket 6 |
| [Halo3/](Halo3/) | Halo 3 | Menus and Forge play at the game's 30 fps with sound; the busiest views can still dip |

No game files are included. Each port needs your own copy of the game disc;
open the port's folder and follow its README (`Start here.bat`).
